# hard_0_e1_0002 Oracle 执行诊断

## 结论

本轮保持规划器与控制器参数不变，只增加逐步执行记录。任务在 `11.5 s` 再次碰撞，和原 35 秒评测一致，因此记录功能没有改变机器人行为。

碰撞的直接原因不是倒车切前进时没有停稳，而是规划参考包含副轴急剧换向，控制器没有为有限的副轴转速提前减速，机器人在副轴尚未到位时切入障碍物膨胀边界。

## 证据

- 规划参考在第 7 到第 8 个路点附近把副轴命令从 `+30°` 切换到 `-30°`。
- 当前副轴速率限制为 `30°/s`，完整换向至少需要约 `2 s`。
- 控制器约在 `10.6 s` 才开始给负转角，此时 truth clearance 约为 `0.24 m`。
- `10.8 s` 时 clearance 约为 `0.10 m`，平面速度仍约为 `0.29 m/s`。
- `11.5 s` 碰撞时副轴实际位置约为 `-8.3°`，尚未建立规划所需的右转曲率。
- 碰撞点相对最近参考点偏差约为 `0.218 m`；规划轨迹自身仅保留约 `0.1 m` 的额外安全裕量。
- 倒车切前进发生在约 `2.1 s`，控制器持续制动至约 `5.4 s` 并已接近停止。这不是本次后段碰撞的主要原因。

## 下一项单变量改动

只增加急转向前的速度门控：当预瞄范围内出现较大的副轴角度变化，尤其是跨零换向时，提前降低主轴目标速度，待实际副轴接近所需角度后再恢复速度。

这一改动先不调整：

- PID 参数；
- `0.1 m` 安全裕量；
- Hybrid A* 搜索空间；
- 35 秒评测预算；
- 碰撞判定标准。

这样可以把成功率变化归因于转向前制动本身。
