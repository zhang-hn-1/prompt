## 已确认的现象与解释边界

1. **时间预算影响部分成功率。** E1_0001 和 E1_0003 在 20 秒后到达。不能把这部分改善记为控制算法改进。
2. **重复运行存在初始状态差异。** E0_0002、E1_0001、E1_0004 的首帧位置相对旧轮相差约 6.3 mm，对齐时间段内轨迹最大差异分别为 0.132、0.128、0.153 m。其他四项对应轨迹前缀完全一致。E1_0004 在 20 秒之前就改变结局，因此该项不能归因于增加预算。初始化和相机预热期间的物理状态需要检查。
3. **换向制动触发偏晚的证据。** 旧轮 E1_0002 发出零目标后、反转命令前仍运动约 0.714 m；E1_0004 对应值约 0.832 m。代码在参考索引进入新方向后才进入停车状态，未完整使用距离切换点的剩余弧长提前制动。
4. **纠正此前的索引诊断。** 旧轮 E1_0004 最后 10 个动作块均为主轴 +0.5 rad/s、副轴 +30°，最后两秒位移接近零；不是输出零命令导致的停车。是否受障碍阻挡或陷入转向饱和还需要回放和完整状态日志，不能把“索引跳到终点”写成已确认根因。
5. **碰撞统计是栅格判定。** runtime 使用局部占据栅格中障碍单元中心距离减机器人半径，clearance <= 0 计碰撞。它不等于已核验的物理接触。旧轮部分任务的 physical_contact 从首帧到末帧恒真，另一些恒假；过滤包含全部场景碰撞体，需要核查地面与障碍是否分离。
6. **稳态原语与瞬态执行存在模型差距。** 规划状态为位置、yaw 和驱动方向，原语依据稳态曲率；尚未显式模拟当前线速度、副轴实际位置、动作平滑和转向响应延迟。副轴目标速率限制为 30°/s，从 -30° 到 +30° 至少需要 2 秒。

## 推荐顺序（待实施）

1. 补充每步审计状态：yaw、世界速度、两轴实际状态、平滑后命令、参考索引和制动阶段；定位首帧差异，并核验障碍接触过滤。使失败可以稳定复现。
2. 优先针对 E1_0002/E1_0004 验证提前制动：用到换向点的剩余弧长和当前实测制动距离触发减速，停稳后切换方向。保留 35 秒协议作对照。
3. 针对 E0_0002 验证弯前减速、转向饱和检测和跟踪误差反馈。仅“慢一点”不是已证明的解决方案，需要检验是否降低实际偏差及碰撞率。
4. 若稳态查表控制仍不足，再扩展到带速度、副轴响应和命令变化限制的短时预测控制。此项属于控制架构升级，不在本轮评估中修改。

当前只有一个场景、七个任务和每种预算一轮运行。汇总中的单场景 bootstrap 区间退化，不能用于证明统计显著性或跨场景泛化能力。
