# 水平航向角速度反馈：E1 有界验证

## 本轮问题

既有导航航向来自机体X轴在世界XY平面的投影，而反馈直接使用world omega_z。机器人有倾斜时二者不等。本轮仅以当前四元数和world角速度计算投影航向导数，替换既有转向反馈中的测量项。主通道、反馈增益、裁剪、映射、规划与记忆不变。两臂使用同一稀疏SGBM来源。

## 当前证据

已封存旧E1共351次捕获/1751次物理采样的只读核验。解析航向导数对物理航向20ms差分的残差p90约0.00349 rad/s，world-z残差p90约0.02640 rad/s。该证据只支持坐标一致性，不证明导航收益。

26项新候选与评分CPU检查、23项既有跟踪检查通过。独立审查发现并关闭三个P2问题：奇异姿态回退评分、实验身份说明、来源帧完整性。旧文件字节及RED/GREEN日志保留。

## 环境启动记录

隔离环境无法访问显卡，最初B0在SimulationApp构造阶段runtime_failed(-11)。尚未创建任务场景或捕获轨迹；原状态、日志、清单、协议和no_retry均保留。宿主只读检查确认RTX3060驱动正常，独立审查登记唯一环境恢复。新版本仅修改环境和输出路由，三份代码归一后AST与原版一致。经工具权限审批，开始宿主两臂各唯一一次35秒实验；禁止再恢复或重试。
