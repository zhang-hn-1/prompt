Existing closed observation-handoff run only; no new simulator, inference, training, or runtime installation. One deterministic candidate, threshold 0.10m Euclidean 3D agreement with previously accepted hazard queries, previous 10s source retention. Static scene and previously seen geometry only. Input whitelist contains present/past packet measurement fields only. Timestamp check precedes payload access. Original frame/eye/query/time and partner identity retained. Exact replay keeps original decision and age; changed same identity rejected. Same-frame points cannot support one another. Matching uses only accepted previous frames within 10s. Translation of XY must preserve decisions. Qualification passed by caller from existing actual handoff state; no offline label input.

Tests first: absent qualification, first qualified seed, agreement/rejection, replay/expiry, future trap, changed-identity rejection, translation and same-frame isolation. Then generate ALL decisions for 71 source frames before reading offline labels. Baseline accepts each current provisional hazard query; retention comparison is same source/time, not different RGB renderer runs. Score post-seed 180..350 inclusive: precision = correct-within-0.10m retained / ALL retained (nonfinite labels remain insufficient and count in unconditional denominator); retention = correct retained / ALL baseline correct hazard queries. Empty denominators cannot pass. Frozen development gates: precision >=0.95 AND retention >=0.80. Report seed separately; scope is development, reused trajectory/labels, NOT fresh validation or safety. Fail -> reject, no threshold scan, reseeding or alternative filter. Pass -> at most one fresh complete-sequence test before any navigation installation. Old global depth gate, Mmem1 reject and navigation failures unchanged.

Outputs: per-query decisions with original IDs/times, all-output hash seal, per-frame errors/counts after seal, fixed metrics, report/source identity/test logs. This is an offline causal algorithm test, not an online navigation result.
