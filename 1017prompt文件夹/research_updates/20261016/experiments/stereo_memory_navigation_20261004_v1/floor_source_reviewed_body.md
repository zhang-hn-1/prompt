# 固定相机下的地面来源核验：平面像素一致性与冻结语义模型

本阶段实际运行了一个平面一致性候选的4次RGB预测和一个固定语义模型的8次RGB推理。两个候选都没有产生通过门槛的地面输出，保留拒绝；没有把平面假设或空输出写入自由地图，也没有机器人控制改变。另完成有限的来源覆盖诊断，不据此断言所有方法或固定相机永远无法导航。

## 范围和预冻结标准

使用此前真实Oracle B0日志中事先选定的0/60/153/307帧（0/6/15.3/30.7s），固定安装/光照、自遮挡mask和原完整轨迹。旧数据为开发诊断，不是fresh。算法只读取RGB及显式已知相机位姿；GT depth在全部预测保存后仅供离线评估。

平面候选假设world-Z=0的平坦地面，将当前左图像素射线与平面相交再投影到当前右图及5帧前左右图。7×7纹理patch、std>=3、ZNCC cost<=.2、视差夹角>=.5deg、至少2来源，完整双线性足迹不被mask遮挡，轴向深度.5—3m。预测只能称“像素支持的平面假设”，不能称独立测得双目深度。没有在未知图上铺一层平面自由先验。

两个新来源实验都在推理前冻结：每帧每视图潜在地面query>=100、全部query正确覆盖>=90%、全部实际输出地面/射线正确比例>=99%、条件射线误差p90<=.10m。GT query由未遮挡有效renderer depth反投影world-height在±.05m、.5—3m范围构成，是旧2.5D高度带代理；不是完整3D物体ID或接触判定。输出还需射线误差<=.1才算正确。分母不删去无匹配来源像素，空输出precision/p90留null而不是通过。

所有旧body-source gate、导航拒绝、在线里程计拒绝及原35秒规则保持。这个狭窄地面来源也不能替代仍失败的通用障碍深度门槛。

## 有限来源选择诊断

`floor_overlap_diagnostic_protocol.json` 在诊断前固定偏移1/2/3/5及左右眼，只用标签分析可见性/视差，没有新RGB候选或改变旧拒绝。5帧前的地面经常已被遮挡；更近1帧虽然可见，运动基线却可能不足.5°。

最近1/2帧左右眼加当前右眼，至少两来源且视差足够的query比例为0、21.079%、0.179%、0；远不到90%。30.7s时较早3/5帧各有761/945个支持，但这不自动认证完整source集合或解释整个导航失败。这个诊断说明必须同时考虑重叠视野和实际视差，不能仅按“过去有图像”认为提供了有效深度。当前冷启动没有过去帧，是明确边界；没有把当前真实运动事后反写为已观测自由。

实际地面像素仍存在。个人额外检查左图query world-Z≤1mm的数量1580/1575/3352/1575，其余初始383在旧±.05m带内；水平距离球心至少1.11/1.73/1.28/1.24m，没有query落在球心.4m内。原高度带不是严格语义ID；这些诊断支持大部分query确实来自远处地面，不把整带误称精确ground segmentation。

## 一个冻结语义候选：8次真实推理

选择小型、可直接运行的SegFormer-B0作室内地面零样本对照，不声称它是最新模型。[论文](https://arxiv.org/abs/2105.15203)、[官方NVIDIA实现](https://github.com/NVlabs/SegFormer)、[固定checkpoint](https://huggingface.co/nvidia/segformer-b0-finetuned-ade-512-512/tree/cc2189cbf3173593452db75308756036c990bc44)。checkpoint版本cc2189cbf3173593452db75308756036c990bc44，实际配置floor ID=3。仅下载静态config/preprocessor/pytorch_model.bin约15.1MB，torch.load(weights_only=True)，没有执行远程代码或安装依赖。

本地transformers4.21.1使用正式SegformerFeatureExtractor接口（新版ImageProcessor导入不可用，失败记录保留）；torch2.5.1，CPU FP32/eval/inference、单线程，官方512预处理。原生图像按固定安装逆时针90°转正，logits双线性回原尺寸、align_corners=False，然后标签/概率反旋转；argmax=floor且p_floor>=.9才作为像素语义候选。模型入口仅RGB/frame/time/eye，位姿不进入分类器；已知平面投影另一个环节，仍不是双目测距。

这支持“该零样本模型不适配当前大部分视野被机器人占据、地面只有狭窄孔洞可见的模拟画面”这一有限判断；不能推出新监督适配一定成功，也不能把这些query正确数量少归因于相机位置一个因素。
