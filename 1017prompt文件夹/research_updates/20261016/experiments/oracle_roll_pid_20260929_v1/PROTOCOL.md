# Roll feedback experiment, frozen before simulation
Bounded modification: wrap the actual 50 Hz ActionSmoother input with a physical-bank PID. Planner, path, main command, actuator protocol, slew limits, auxiliary velocity supervisor and 35-second evaluation remain unchanged. Existing B0 source is not edited. This is an experimental execution adapter, not an exact reproduction of unknown real-robot PID gains/output interface.

Bank = asin(2*(w*x+y*z)) from normalized base_link world quaternion; physical +Y elevation. Raw requested auxiliary is clipped by existing protocol, then desired bank = 0.75 * protocol auxiliary. This conservative target conversion is a provisional approximation informed by previous long-hold responses, NOT a claimed curvature law. PID output is auxiliary POSITION target with original auxiliary as feedforward, negative feedback on measured bank and filtered bank rate. Current measured state only, at 50 Hz, no future log. Integral limited to 5 degrees output, conditional integration at angle saturation and downstream supervisor restriction. Candidate initial gains Kp=.8, Ki=.10/s, Kd=.35s, derivative lowpass tau=.1s. Only if open-plane unstable, at most two additional gain settings (.4,.05,.25), (.2,.025,.15); no navigation-based retuning.

Probe at main .5 and 1.5 rad/s: 0-5s upright,5-15s requested aux +20deg (desired bank +15),15-25s -20deg,25-35s upright. Same initial reset, no reset inside sequence. Paired B0/PID each speed; tail windows12-15,22-25,32-35s. Measure bank RMS/peak error, bank rate RMS, actual speed, clipping/supervisor. Safety gate: finite states, abs bank<35deg, no new >10deg sustained oscillation in tail; report any failure. Select initial candidate if aggregate tail RMS not worse than B0 and upright tail not >2deg worse; otherwise bounded alternatives and explicit rejection if all fail. All failed runs retained. Only open-plane evidence selects gains.

Navigation: frozen selected candidate on golden 3 and hard_0 7, original 35s criterion first distance<=.2m; actual contacts reported separately. Compare with preserved 20260928 B0 of same source/config and freeze hashes. If source differs rerun B0. Even if candidates rejected, provide concrete benchmark diagnostic for initial candidate, labelled rejected, no production promotion. Never pool duplicate golden E0/hard_0 E0 as independent cases. No claim of held-out generalization (known suites).
