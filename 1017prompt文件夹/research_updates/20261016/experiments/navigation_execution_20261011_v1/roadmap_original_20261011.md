## 审查重点

1. 局部误差下降或停得更早，是否被误写成到达改善。
2. 已知位姿、估计位姿和仿真真实速度是否混用，导致低估实际感知难度。
3. 大量未知或不支持窗口是否从分母中消失，导致条件误差冒充总体性能。

- [ ] 编写该改动的具体实现计划，指定真实policy owner、读写字段、调用时序和现有文件；在这一步才确定新代码接口。
- [ ] 在原协议量纲下事前冻结数值门槛：到达、接触、目标剩余距离、净进度、横向偏离、未知区风险及端到端时延；检查门槛是否逻辑可满足。
- [ ] 实现唯一消费改动，并针对真实接口进行必要测试：时钟与历史截断、异常输入、换向或制动分支、单次调用与状态恢复。独立审查实现和评分来源。
- [ ] 建议新阶段预算上限为已知位姿E1两臂各一次35秒。只有版本与输入可比性充分成立才复用历史B0，否则在新协议内运行同版B0；此预算是计划建议，尚未形成启动协议。
- [ ] 完成原始轨迹、接触、请求与指标核对，保留未介入、接口失败、覆盖不足和性能失败各自的真实分类。

## 任务三 分层完成估计位姿与场景评测

**输入：** 已冻结的基线，以及任务二中值得进一步评价的候选（若有）。

**产出：** E0/E1/E2按位姿条件分开的导航结果，以及定位误差与控制效果的可解释比较。

- [ ] 先在估计位姿E1评价保留候选，记录位姿、航向、记忆配准与请求变化；真实状态仅作明确标注的诊断或评分来源。
- [ ] 完成事前冻结的E0/E2覆盖。若采用“两种方法×两种位姿×三个场景”，总计为12个条件；已通过可比性审查的运行可计入，不能将每轮历史E1都作为新样本。
- [ ] 对位姿关联的失败，只定位一个独立问题；不同时修改里程计、规划和控制后宣称单项收益。

**完成标准：** 各条件有终态、到达/碰撞/超时、进度及特权说明。基线成功率低不妨碍它作为诚实的基准结果；可靠导航的主张需要额外预注册的独立起点或场景验证，三场景开发结果不足以支持泛化。

## 任务四 明确空间记忆的实际作用

**输入：** 已冻结且接口可运行的导航版本、相同双目来源和位姿条件。

**产出：** 当前观测与显式历史风险记忆之间的一项公平消融。

- [ ] 先审查历史消融能否满足当前版本和研究问题，满足则直接引用其有限结论。
- [ ] 仅在仍有关键证据缺口时，固定current-only与history-memory两条件，以及场景、预算和未知语义；不能通过不同安全规则或先验制造方法优势。
- [ ] 同时评价遮挡后风险保留、错误清除/假自由、实际请求差异、碰撞与到达。风险地图保存更多障碍不自动等于导航更好。

**完成标准：** 能说明记忆在哪些条件改变了真实导航，或没有带来收益。相关消融的场景数量与重复预算在运行前确定，不自动开启新矩阵。

## 任务五 按数据覆盖决定学习路线

**输入：** 已有覆盖不足结论，以及一个与旧关闭候选有实质区别的研究问题。

**产出：** 一个可执行的新学习实验设计，或暂不具备训练条件的明确结论。

- [ ] 先明确学习目标、真实在线输入与消费者；数据准备可以推进，正式控制接入取决于独立资格，不要求传统基线先达到3/3。
- [ ] 若需要新数据，设计独立的整序列采集与留出划分，覆盖不同状态、命令、遮挡和失败情况；与旧候选的扩库、改阈值或重训救分严格区分。
- [ ] 在训练前检查覆盖和标签语义。未来真值只作监督或评分，不得混入在线特征；所有锚点都保留在覆盖分母中。
- [ ] 覆盖通过后仅训练一个冻结候选，与适用域内的简单比较器评价；数值门槛及预算在独立设计里事前固定。
- [ ] 只有离线覆盖、误差、时延与接口均合格，才设计一次真实消费者对照；到达率未改善时不得仅凭预测误差宣称导航收益。

**结果分支：** 覆盖不够则停止该候选，不反复换模型。学习失败也可以形成严谨研究结果；可靠估计位姿导航若仍未实现，必须单列为未完成目标。
