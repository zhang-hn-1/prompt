# Measured transition pilot
Run with the repository ball_wm Python environment and root+scripts PYTHONPATH. run_all.py refuses existing per-run output directories. runtime.set_reference_visualization_path is required even for prescribed-action open-plane runs; the reference only supplies the harness fixture/visualization, no policy.act is called.
Each successful run uses 8s preconditioning + 4s requested steering reversal with no internal reset. Boundary state and prediction_status provide the causal timing. First two measurement sequences are frozen before either repetition. Repeatability uses recorded state equality; no tolerance matching or unknown-state extrapolation.
The observable boundary snapshot is NOT all internal PhysX/contact-solver state. Equal recorded state alone does not prove general Markov-state sufficiency. In these tests the entire reset/prefix is identical.
assess.py exports local-frame measured XY, body-yaw change, joint response and command stages. The body radius is .4m; exported center samples are swept-center evidence, not a continuous collision certificate. Not installed in the production planner.
failed_start and failed_start_with_trace retain two failed startup attempts before data collection. Root cause: missing injected diagnostic reference. Fixed by same injection as prior working harness. No valid transition samples were produced by those attempts.
