# 动作条件执行记忆的有限检索实验

2026年10月10日，新的有限轨迹记忆已实际完成一次离线建库和预测评价。固定30个测试锚点中，只有6个同时满足检索支持、未来完整覆盖和实际命令遵守所提出的程序，低于事前冻结的24个总量与每序列8个门槛。因此结论是 **coverage_unassessed**，不能接入命令排名消费者，也不能把小范围误差较低称为导航通过。整个导航研究尚未完成。

## 方法与范围

输入为当前及过去5帧状态、请求历史，以及在当前时刻独立提出的保持当前请求0.5秒的命令程序。不可变记忆从4条历史完整序列建立，最多272个候选窗口，实际153个符合训练程序与接触覆盖条件；测试为另2条完整序列的固定30个锚点。使用固定尺度的最近一条轨迹检索，无新网络、回归拟合、采集或物理运行。

这是使用仿真当前状态和姿态的离线诊断。测试序列此前被其他工作查看过，属于本候选的整序列开发留出，不是新鲜测试、OOD或纯RGB在线导航。归档请求日志在预测阶段整体解码，但特征与提案只消费当前及过去索引，未来真实请求只在预测封存后的教师阶段评价提案遵守情况。未来真值只用于训练标签或封存后评分。

误差只描述6个可评分窗口，不能隐藏其余24个或推断完整运行的精度。冻结四点稳态比较器仅在其精确请求域可用：E1只有1个窗口的5步，RMSE 0.056776m；E2没有可比窗口。这不证明其瞬态预测正确，也不构成总体优劣结论。

对同一30个已保存预测作支持分解，无新查询：10个检索支持、6个没有容差内命令程序、13个状态距离超出固定支持域、1个锚点缺失。其中10个支持窗口有4个未来实际程序不遵守保持提案，最后仅6个进入评分。主要限制是固定记忆域覆盖与闭环提案遵守，不能凭增密双目或只展示低误差解决。
