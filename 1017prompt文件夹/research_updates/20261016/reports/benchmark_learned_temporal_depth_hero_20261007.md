# 球型机器人：唯一 Hero 时序深度候选的实测与拒绝

这轮实际运行了 MVSAnywhere Hero：它读取当前 RGB、过去约 1/2 秒的同眼 RGB 和已知相机位姿，在双目共同视野不足时提出新的三维点。点数与新区域覆盖增加，但六组结果全部未达到原 95% 几何正确率门槛，**拒绝接入导航**。研究整体尚未完成，正式原 35 秒 E0/E1/E2 尚未触发。

这是封存开发数据上的已知位姿诊断，不是 fresh held-out、估计位姿导航或在线闭环验证。没有新采集、动作、视频或导航成功率。原相机位置、光照、控制器和历史拒绝结论保持不变。

## 实际方法与身份

官方来源：[MVSAnywhere 论文](https://openaccess.thecvf.com/content/CVPR2025/html/Izquierdo_MVSAnywhere_Zero-Shot_Multi-View_Stereo_CVPR_2025_paper.html)、[官方 GitHub](https://github.com/nianticlabs/mvsanywhere)。选择依据是任意多视图、度量相机位姿输入与本项目时序可见性问题的匹配；没有测试其他网络组成模型扫描。StereoAnywhere/VGGT 仅作为文献参考。

源码 commit `5bd49bba0992aa56060e1aa3bb40b2150b04726f`，DINOv2 依赖 commit `7764ea0f912e53c92e82eb78a2a1631e92725fc8`。Hero 官方权重 2,420,601,860 字节，SHA256 `00878bab903b1d384cd6bb9ea092e247a9036d429cb8bcc3d6dcbb81f67e556d`。848.67 秒取得相同文件，没有实际使用 HTTP Range 恢复。依赖隔离安装，不降级原 Torch。

RTX3060、Torch 2.5.1+cu121、float32/eval、native 640×480、ImageNet 归一化；两过去源、初始深度 .5–3m、官方 refinement=1。每个请求有两次内部 forward。没有训练、GT 对齐或改变模型参数。内部 range refinement 可以调整内部深度范围，最后保留查询仍在原 .5–3m。

USD 相机 −Z 转光学 +Z；模型使用半像素中心，K 的中心为 (320,240)，原 native 整数中心为 (319.5,239.5)。matching K 的前两行除以四。当前与过去位姿都来自归档曝光，属于明确的 known-pose 特权。独立曝光时钟核验先于 RGB/pose/CAD payload 读取；整批输入身份在首次 GPU 推理前封存。模型单次只能读取该时刻及过去两个源，保管时封存所有文件不等于把未来数据交给模型。

查询 stride=2、当前及两过去全部 7×7 CAD/FOV 支持、正相机 Z、原高度 .05–1.5m、距 root>.55m。模型没有 CAD token 输入，查询遮挡过滤不证明内部特征或 attention 没有机体影响。所有输出标为 learned hypothesis，未认证为观测或自由空间。

## 原失败和唯一行政修复

首次 GPU 请求实际执行，但 native 输出尺寸断言失败；原日志、输入 seal、运行身份均保留。没有点包或几何评分。checkpoint 配置 prediction_scale=.875；直接 adapter 遗漏官方 loader 必做的 `depth_decoder.set_prediction_scale(1.0)`。原失败日志没有实际 tensor shape，不倒推冒充实测。

真实官方 CPU decoder 小夹具复现输出 28×42，而 native 应为 32×48；测试 RED→GREEN，唯一改动为上述官方 API 调用，所有参数不变。新的独立 v2 namespace 再封存输入，只运行原六组一次；不是调分辨率救分。实际历史为一次失败 GPU 请求加六次恢复请求。557 个 state tensor 全量严格相等；旧/新最终 tensor-stream SHA 都是 `03008367e4f6955d43697d4296c5cd2282ed10e0deb1af4b76124ea264668f83`。不再恢复或更换模型。

## 错误层分解：作者的封存后诊断

当前曝光自身已有 53620 个有限几何错误、23706 个不足标签；不是仅由过去遮挡或历史对应关系造成。各包当前轴向深度偏差中位数 +.061/+ .086/+ .099/+ .100/+ .091/+ .104m，即多数倾向估得更远。当前世界点误差中位数 .064–.109m。尚未证明唯一物理、标定或网络原因；不能用 GT 拟合偏移再重评分救分。

当前标签不足区域的灰度与 7×7 纹理标准差中位数均为零。官方 sky 概率≥.5 的查询数六包都是零，不能靠这个已有 flag 排除这些区域。GT 无限深度不等于真值 sky 分类；背景、遮挡和缺失采集尚需进一步区分。

原 std≥5 的观测域参考也会删掉绝大多数真实弱纹理墙面，因此不能把高纹理筛选作为无代价修复。本轮没有新增 sky/std gate、尺度校正或推理。错误图是预测后标签，不能反馈进决策。

完整项目 CPU 回归 **501 passed / 24.94s**，排除隔离第三方源码目录，原第三方 collection error 日志保留。当前恢复结果的首次独立证据验证 **C0/I0/M0**：亲自重算六包/三端点评分、161908 查询的 23800476 个支持 tap、源码/输入/输出/权重文件 SHA 与时间顺序，11 个因果 guard 测试通过。模型参数全量比较、GPU latency、全501测试由作者执行，reviewer 仅检查相应证据；不能把 digest 对比写成 reviewer 重新加载557参数。新错误层/sky 诊断是作者执行，未伪称在独立 review 范围。

主要数据位于 `experiments/stereo_memory_navigation_20261004_v1/mvs_hero_temporal_development_v2_api_scale_recovery/`；首次独立验证见 `mvs_hero_first_result_evidence_validation_v1.md`，原 v1 失败和 seal 保留。没有新视频，上一轮实际碰撞视频仍保留。
