**目标期刊：IEEE Transactions on Robotics (TRO)**
**时间周期：6个月**
**评审得分：9.1/10 (READY)**

---

## 一、研究背景与动机

### 球型机器人的特点
- 全封闭球形结构，防爆防摔，适合矿井/灾区/户外复杂场景
- 依靠内部2-DOF重锤摆驱动，转向必须通过重心偏移实现
- 转向时球壳同步旋转 → **摄像头视角随运动强耦合变化**

### 核心问题
现有视觉世界模型（DINO-WM等）隐含假设"摄像头视角固定或变化微小"。球型机器人转弯时，相机同步旋转，同一场景的DINOv2特征分布**完全改变**，世界模型预测失效，ImageGoal导航崩溃。

这个问题不只针对球型机器人，**四足机器人（步态抖动）、无人机（姿态变化）**同样存在。

## 二、研究方案：EV-WM

**全称**：Explicit Viewpoint State Latent World Model for Motion-Coupled Visual Navigation

### 核心创新点

```
现有方法（DINO-WM）：
  (z_t, a_t) → ẑ_{t+1}
  视角变化隐含在特征里，MPPI rollout中无法传播

本方法（EV-WM）：
  (z_t, r_t, a_t) → (ẑ_{t+1}, r̂_{t+1})
  r_t = 显式视角状态 = [sin(ψ), cos(ψ), sin(φ), cos(φ)]
  MPPI rollout同时传播场景特征和视角状态
```

### 技术组成

#### 1. 显式视角状态 r_t

```
r_t ∈ R⁴ = [sin(ψ_t), cos(ψ_t), sin(φ_t), cos(φ_t)]
ψ = 偏航(yaw)，φ = 俯仰(pitch)
参考系：相对episode起始帧，r_0 = [0,1,0,1]（天然初始化）
```

#### 2. Ray-Conditioned Token Interaction

```
ray_i(r_t) = R(r_t) · base_ray_i   ← 用视角状态旋转patch射线
token_i' = Linear([z_i, ray_i(r_t)]) ← 几何感知token
```

视角旋转直接体现在token的射线方向上，不需要像素级投影。

#### 3. 多步Closed-Loop Overshooting训练

```
训练损失：
L_total = L_scene + λ₁·L_vp + λ₂·L_Kstep

L_scene  = cosine_loss(ẑ_{t+1}, z_{t+1})      ← 场景特征预测
L_vp     = sin-cos角度损失(r̂, r*)              ← 视角状态预测
L_Kstep  = Σ_{k=1}^{3} γ^k·cosine(ẑ_{t+k}, z_{t+k})  ← 3步rollout

训练时50%用预测的r̂（不用teacher）→ 与MPPI推理行为对齐
```

#### 4. 系统架构

```
双目RGB → [冻结DINOv2] → patch特征 z_t
双目RGB + IMU → [轻量位姿头] → r_t（由DUSt3R离线伪标签监督）

[z_t, r_t] → ray-augmented tokens
[token历史, r历史, 动作历史] → [EV-ViT] → (ẑ_{t+1}, r̂_{t+1})

MPPI规划：K步closed-loop rollout → 选最接近目标图像特征的动作
底层控制：已有PPO控制器 @ 50Hz（joint1速度控制 + joint2位置控制）
```

## 三、仿真验证平台（已搭建）

### 硬件配置
- **平台**：自研球型机器人，直径0.8m，2-DOF重锤摆驱动
- **摄像头**：左右双目RGB（640×480，hfov≈79°），安装位置：前+0.1m，左右±0.3m，高+0.1m
- **传感器**：IMU + 轮速计（本体感知已有）
- **计算**：机器人GPU（推理）+ GPU服务器（训练）

### 仿真环境（已完成）
- **仿真器**：IsaacSim 4.5 + `ball_wm` conda环境
- **场景**：MP3D-PE 室内场景（90个，InternNav验证过，带物理碰撞和材质渲染）
- **控制**：
  - joint1（Y轴）：速度控制（kp=80，目标速度1 rad/s）
  - joint2（X轴）：位置控制（kp=500，摆角±0.2rad）
  - 键盘交互控制（W/S前后，A/D转向）

## 四、训练数据方案

### 数据采集
```
来源：真实机器人 + 仿真（IsaacSim MP3D场景）
内容：双目图像序列 + IMU + 电机指令
规模：500-1000条轨迹（~50k帧）
策略：随机动作覆盖直行/转弯/加速等多种模式
```

### 视角状态标签
```
离线处理：DUSt3R对采集数据产生高质量相机位姿序列
提取r_t：从位姿序列计算相对起始帧的yaw/pitch
置信度加权：低纹理/运动模糊段自动降权
```

## 五、实验设计

### 主实验（Claim 1）：转弯场景SR提升

| 对比方法 | 说明 |
|---------|------|
| DINO-WM | 无视角状态基线 |
| ReL-NWM | 轻量潜空间，无视角感知 |
| ANWM | 有视角感知但像素级，重量 |
| **EV-WM（ours）** | 显式视角状态 + ray-conditioned |

**路线设计**：高转弯组（总转向>90°）vs 低转弯组（基本直行）  
**核心预期**：高转弯组SR差距>20%，低转弯组差距<5%

### 支撑实验（Claim 2）：跨平台表示迁移

冻结EV-WM，仅训练小型适配头，在公开四足数据集（HuRoN/ReCon）评估转弯预测误差

### 消融实验

| 消融项 | 验证内容 |
|--------|---------|
| r_t=0 → DINO-WM | 显式视角状态必要性 |
| bias → ray interaction | ray条件化表达力 |
| 1-step → K-step训练 | 多步overshooting必要性 |
| 无DUSt3R置信度加权 | 伪标签质量控制价值 |
