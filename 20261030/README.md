## 项目思路

建议先选择一个已经成熟的普通机器人目标识别与跟踪项目，完整跑通以下基线链路：

1. 相机采集与目标检测；
2. 多目标/单目标跟踪与身份保持；
3. 目标位置估计与跟随控制；
4. 可视化、日志和量化评测。

先跑通普通机器人方案，可以验证检测模型、跟踪器、坐标系转换和跟随控制等基础模块，也能得到一套可复用的基准结果。

## 球形机器人的关键差异

球形机器人与普通轮式、履带式或足式机器人最大的不同，是相机通常随球体一起运动：机器人滚动、转向或受到冲击时，镜头会同步发生明显的俯仰、横滚和抖动。

这会导致普通跟踪项目中的一些常见假设失效：

- 画面背景整体漂移或旋转，目标在图像中的运动不只是目标自身运动；
- 剧烈晃动带来运动模糊、卷帘快门畸变和短时遮挡；
- 目标容易在画面中快速跳变，甚至短时间离开视野；
- 仅依赖相邻帧位置连续性的跟踪器容易跟丢或发生身份切换；
- 直接根据图像误差做跟随控制，可能形成越晃越追、越追越晃的反馈。

## 创新方向：镜头剧烈晃动时仍能识别并跟随

围绕相机随球体晃动这一特征，可以从以下几个方向做创新：

### 1. 晃动感知的视觉补偿

利用 IMU、陀螺仪和里程计估计相机姿态变化，对相邻帧做旋转补偿、去模糊或视场校正，把相机晃动造成的背景运动和目标的真实运动分离开。

### 2. 抗模糊与抗抖动的目标识别

针对高速滚动场景构造运动模糊、旋转、曝光变化和随机抖动增强数据；结合多帧融合与时序检测，避免单帧漏检导致跟踪中断。

### 3. IMU 辅助的预测式跟踪

将 IMU 姿态变化作为跟踪器的运动先验，使用卡尔曼滤波、扩展卡尔曼滤波或粒子滤波预测目标在下一帧可能出现的位置；当目标短暂丢失时，在预测区域和全图之间自适应切换重检测。

### 4. 晃动条件下的身份保持

融合外观特征、运动轨迹和相机运动补偿结果，降低剧烈晃动造成的 ID Switch；对短时丢失设置可恢复的轨迹缓存，而不是立即删除目标。

### 5. 稳定性优先的跟随控制

将目标预测轨迹与机器人自身姿态、角速度和相机晃动幅度一起送入控制器，在镜头剧烈晃动时降低激进跟随，加入姿态前馈和运动平滑，优先保证目标始终处于可控视野内。

## 建议实施顺序

1. 跑通普通机器人目标检测与跟踪基线，保存视频和评测结果；
2. 在基线中加入相机抖动模拟，观察跟踪失败模式；
3. 接入 IMU 或姿态数据，实现帧间运动补偿；
4. 加入运动模糊与随机晃动数据增强，训练抗抖动检测模型；
5. 实现预测式跟踪、丢失重检测和身份恢复；
6. 将跟踪结果接入跟随控制，完成球形机器人闭环测试；
7. 建立剧烈晃动场景数据集，持续对比基线方案。

## 评测指标

- 目标检测召回率与误检率；
- 跟踪成功率、MOTA、ID Switch 次数；
- 目标中心像素误差与轨迹抖动程度；
- 剧烈晃动、运动模糊、短时遮挡下的跟踪存活率；
- 跟随过程中目标保持在画面中心区域的时间比例；
- 机器人跟随速度、角速度与姿态稳定性。

## 目标

最终形成一个面向球形机器人的视觉跟踪方案：不要求相机绝对稳定，而是让算法在镜头剧烈晃动、目标快速运动甚至短时丢失的情况下，仍能重新识别目标并稳定跟随。

当前目录先提供外参核对三维示意图；后续代码、实验数据和评测结果可按上述方向逐步补充。
